## Per-profile notes
- **Tiger**: Tour Tempo measured 27/9 (to 1997), 24/8 (2002 on), both exactly 3:1 by frame counting; real ratio is probably 2.8-3.2. TrackMan snippets: 2012 118 mph/175 mph; 2018 118-120/178-181, smash ~1.51, launch 11-16, spin 1.9-3.0k; older guide ~124/184. Forum post 125/185 is low reliability.
- **Scott**: 56 BPM tempo, 3:1; Sportsbox stresses full turn (~100 deg chest "excellent", >90 good), pelvis sway ~0 at top, negative sway gap (-4 to -8 in) at impact: these read as generic tour benchmarks, so flagged unverified as Scott-specific.
- **Bryson**: figures are Sportsbox (vendor video-AI), not radar. 146.9 mph is a reported peak of unclear context. Equipment: 45 in, 5.5 deg loft, 59 deg lie, jumbo grip. Setup qualitative: high hands, small left-wrist hinge, wide arc, weak lead-hand grip.
- **Gotterup**: big turn, trail leg straightens, weight to trail heel, hard lead-foot push, weak trail-hand grip (Golf Digest / Australian Golf Digest). One coach says ball slightly back of traditional with forward shaft lean; Golf Digest says ball forward. Conflict recorded, not resolved.
- **Scheffler/Rory**: only CHS is published; style parameters are the generator's approximations (`data/generate_synthetic_scott.py`).

## Design: "Mason vs profile"
Inputs: `mason_target_features.json` (tempo, durations, `tempo_rel_uncertainty`), self-reported 120 mph from `power_profile_350yd_targets.json:mason_gap`, and `pro_swing_profiles.json`. `mason_impact_geometry_targets.json` is intentionally not scored (hand-height/low-point proxies have no published pro counterpart).

1. **Comparable features only** - tempo_ratio, backswing_s, downswing_s (video, ~30 fps) and club_head_speed_mph (self-reported). Each has an uncertainty and trust weight (tempo 0.35; seconds 0.2; CHS 0.5). Mason's pelvis/thorax/X-factor/peak speeds/launch data do not exist, so they are never scored.
2. **Delta and band position**: `delta = mason - target`; `band_position = 0.5 + delta/(max-min)` (0.5 on target, 0/1 at the band edges). This is a band position, not a population percentile. Missing/too-narrow bands fall back to an assumed relative tolerance (flagged `*`).
3. **Significance** = `|delta| / sqrt(half_band^2 + mason_unc^2)`; <1 = inside noise ("no change indicated").
4. **Priority** = significance x mason_trust x profile_confidence_weight (high 1, medium .75, low .4, none 0) x 0.5 if the profile value is unverified. Ranked per profile and averaged across the style profiles.
5. **Output wording** is hedged by trust. Speed gaps are labelled "not a technique item"; downswing/backswing seconds gaps say "probably a 30 fps artifact, re-measure at 240 fps".
6. **Measure next** list: launch monitor, 240 fps video, pelvis/thorax turn, segment peak speeds, setup photos.

## Key findings (current data)
- Tempo ratio: Mason median 2.9 (IQR 2.875-3.55) is consistent with all profiles (Tour ~3.0, Tiger/Scott 3:1, Rory 2.8); no change indicated; uncertainty is ~+-27%.
- Backswing/downswing seconds are far shorter than published tour values (0.48/0.17 vs ~0.75-0.80/~0.26). Likely artifacts of sped/edited feed clips and ~30 fps detection, so no action recommended. Re-film at 240 fps.
- Club speed (self-reported 120): at Scott/Tiger/Scheffler level (~120), ~3-5 mph under Rory/Gotterup (123-125), ~8 under the Bryson-style 128 and ~7 above the TrackMan tour average (113). Needs a launch-monitor session.
- Nothing about X-factor, sequencing, setup or attack angle can be concluded yet.

## Caveats
Published values are heterogeneous (vendor AI, media, single shots, different years/equipment). Handedness: values are magnitudes; mirror for a left-hander. The 350 yd work (`docs/research_350yd_profile.md`) covers the power-target ladder; this file is about style comparison.
