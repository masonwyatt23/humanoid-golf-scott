`landmarks (m,33,4)` (60 Hz world landmarks), tempo/timing fields and `quality_score` (0-1 heuristic).
Joints: col 0/4 shoulder "pitch" = 0 when the arm hangs along the torso (angle wrap fixed 2026-10-16).

Instagram playback (re-encoded, ~30 fps unique frames), so tempo is +-15%; joint angles are 2D-proxy angles from
MediaPipe world landmarks, NOT retargeted/IK-solved to the MuJoCo humanoid; no club data; leg joints (cols 5-10)
are unreliable when `leg_valid_frame_ratio` < 0.6. Not Adam Scott style data: this is Mason's swing.

## License / provenance tags (all files in data/references/)

Every `.npz` carries `license_class`, `commercial_ok`, `provenance_source`, `provenance_note`,
`acknowledgment_required`, `acknowledgment_text` (see `data/provenance.py`; retro-tag with
`python -m data.tag_provenance`; generators/converters tag new files automatically).

| Files | license_class | commercial_ok | Conditions |
|---|---|---|---|
| `scott_/scheffler_/rory_/average_swing.npz` | synthetic | yes | Procedural, textbook parameters; not measured data |
| `mason_swing_*.npz` (incl. `_refined`) | self_owned | yes | Instagram-recorded footage of Mason's own swings; confirm no third-party content/music |
| `cmu_64_01..10.npz` | cmu_permissive | yes | Include CMU acknowledgment (`acknowledgment_text`); no standalone resale of converted data |
| GolfDB / AMASS / SportsPose etc. | noncommercial | **no** | none present currently |
| anything untagged / `process_video.py` output | unknown | **no** | retag with `tag_provenance --force` once origin is known |

Filter: `from data.provenance import include_commercial_only`; or
`ReferenceDataset(dir, commercial_only=True)` (default False, existing callers unchanged; each ref dict also gains
`license_class` / `commercial_ok`). Env/eval/train were not modified; to enforce in training, pass
`commercial_only=True` wherever those call `ReferenceDataset`/glob references (not done).


## Mirrored Mason references (`mason_*_mirrored.npz`)

Generated by `python -m data.mirror_references` (`data/mirror_references.py`); originals untouched, one
`_mirrored.npz` beside each `mason_*.npz` (25 files, incl. the 10 `_refined`). Tests: `tests/test_mirror_references.py`.
Same provenance tags as source (self_owned, commercial_ok). New fields: `mirrored=True`, `mirrored_from=<source file>`,
`original_handedness` (source value, `right`), `assumed_handedness='right'`, `player_stated_handedness='left'`, `handedness='left'`.
Rules: legs (cols 5-7 <-> 8-10) swapped, shoulder roll (col 1) negated, flexion angles (elbow/wrist/knee/ankle/pitch) unchanged,
arm chain 0-3 stays in place (col 4 has no elbow/wrist partner), pelvis/thorax rotation, x_factor, lateral sway and
club_head x negated (when present), landmarks x negated with L/R indices swapped, events/time/tempo unchanged.
Handedness note: the originals assumed right-handed; Mason states he is left-handed, so the mirrored files are the
likely-left-handed-consistent versions; verify against video. Mirroring is not applied in the env.
Caution: globs like `mason_*.npz` now also match mirrored files (double counting); filter on `mirrored`.
